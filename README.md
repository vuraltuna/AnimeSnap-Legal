# AnimeSnap Legal Pages

Public support and privacy pages for AnimeSnap.

## URLs

After enabling GitHub Pages for this repository:

- Support: `https://vuraltuna.github.io/AnimeSnap-Legal/`
- Privacy Policy: `https://vuraltuna.github.io/AnimeSnap-Legal/privacy.html`

## GitHub Pages Setup

1. Create a public GitHub repository named `AnimeSnap-Legal`.
2. Push this folder to that repository.
3. Open repository settings on GitHub.
4. Go to `Pages`.
5. Set `Source` to `Deploy from a branch`.
6. Set `Branch` to `main` and folder to `/root`.
7. Save.

GitHub usually publishes the pages within a few minutes.
